# paneltracker-site

Marketing and support website for my iOS apps, hosted on GitHub Pages.

## Apps
- **Methodist Panel Tracker** — field tool for managing electrical panels.
- **GridIQ Pro** — smart load monitoring and analytics for electrical pros.

## Pages
- `index.html` — landing page (hero, apps, features, FAQ, contact)
- `support.html` — support & FAQ
- `privacy.html` — privacy policy
- `styles.css` — shared styles (light/dark mode)

## Local preview
Open `index.html` in a browser, or run a static server:

```bash
python3 -m http.server
```
